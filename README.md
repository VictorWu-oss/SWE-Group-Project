# SWE Group Project

## Setup

```bash
npm install
```

## Commands

- `npm run dev --workspace react-frontend` starts the Vite
  development server.
- `npm run lint` checks the frontend source with ESLint.
- `npm run build` creates the frontend production build.
- `npm test` runs the frontend lint and production build checks.
- `npm run format` formats supported source and documentation
  files.

The Express backend workspace is scaffolded and currently has no
application code or tests. Its placeholder test command uses
Node's test runner so the workspace remains compatible with the
repository checks while backend work is added.
